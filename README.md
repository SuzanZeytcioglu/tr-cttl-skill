# tr-cttl-skill

`tr-cttl-skill` provides a controlled, deterministic set of rules and prompts for AI coding agents and documentation generators to produce standardized Controlled Turkish Technical Language (CTTL).

It enforces controlled vocabulary, unambiguous grammatical structures, and strict state representation rules to ensure precise, clear, and maintainable software architecture docs, system specifications, and API documentation in Turkish.

### Key Features

* **Controlled Technical Vocabulary:** Standardizes Turkish technical terminology across system architecture, API definitions, and operational specs to eliminate ambiguity.
* **ISO/IEC/IEEE Standard Alignment:** Enforces document structures compliant with TS EN ISO/IEC/IEEE 26514 and related Turkish standards for developer/system documentation.
* **Deterministic Grammar Rules:** Restricts sentence length, passive voice misuse, and multi-meaning verb structures for optimal machine readability and translation compatibility.
* **Immutable State Rules:** Eliminates non-reproducible inline historical change logs in favor of immutable state snapshots and explicit current-state documentation.
